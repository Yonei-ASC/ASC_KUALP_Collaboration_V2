## 📝 프로젝트 소개
마약 범죄의 재범률이 급증함에 따라, 출소자들의 상태를 과학적으로 분류하고 그에 적합한 사회 복귀 지원(PDS)을 연결하는 것이 중요해졌습니다. 본 모듈은 연구진이 제안한 수식을 바탕으로 사용자의 상태를 분석하고 최적의 정부 지원 정책을 추천합니다.

### 🧬 핵심 알고리즘
진단 점수는 다음과 같은 **재사회화 분류 공식**에 의해 산출됩니다.

$$L = k ( X + Y + Z )$$

- **X (과거 범죄 이력)**: 구속 경위, 범행 종류, 투약 기간 등 (100점)
- **Y (사회 환경)**: 거주 안정성, 사회 자립도, 가족의 지지 등 (100점)
- **Z (단약 의지)**: 중독 인정, 치료 프로그램 이수 의지, 약물 검사 결과 등 (100점)
- **k (재범 상수)**: 지속적인 양성 반응 시 점수와 관계없이 즉시 최하 등급 부여

## ✨ 주요 기능
- **인터랙티브 진단**: 15개 문항을 통해 사용자의 재범 위험도를 다각도로 분석합니다.
- **등급별 결과 도출**: 총점에 따라 1등급(안정), 2등급(관리), 3등급(주의)으로 분류됩니다.
- **PDS(정책전달서비스) 매칭**: 등급에 따라 법무부, 고용노동부, 보건복지부 등의 실제 지원 정책(주거, 취업, 심리치료 등)을 카드 형태로 제안합니다.
- **반응형 UI**: PC와 모바일 환경 어디서든 쾌적하게 이용 가능합니다.
